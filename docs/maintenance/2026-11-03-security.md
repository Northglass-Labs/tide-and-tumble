# Security maintenance — 2026-11-03

This patch updates the public application's framework dependency from Next.js
16.3.6 to 16.4.3. The earlier version was affected by unauthenticated remote
code execution, denial-of-service, server-side request forgery, cache, and
information-disclosure advisories. Next.js 16.4.3 is beyond every affected
range reported by the package audit and retains the existing application and
deployment architecture.

The matching ESLint configuration is also 16.4.3. The lockfile resolves Sharp
0.35.5 and source-map-js 1.2.2, closing the two remaining high-severity
production dependency findings.

## Verification

The exact candidate passed the repository's local release gates:

- `npm ci` installed the committed graph successfully;
- `npm ls --all` reported no dependency-tree problems, with Next.js and
  eslint-config-next 16.4.3, Sharp 0.35.5, and source-map-js 1.2.2;
- `npm audit --omit=dev` improved from one critical and two high findings to
  zero findings;
- `npm test` passed all 34 tests, `npm run lint` was clean, and
  `npm run build` generated all 110 static pages successfully; and
- the production server returned the expected application shell and a 200 JSON
  response from the tide API.

The complete development graph improved from 24 findings (one critical, five
high, and 18 moderate) to 21 findings (zero critical, three high, and 18
moderate). The remaining high paths are development-only Undici, Vite, and Zod
dependencies; they are not in `npm audit --omit=dev` and remain separate
toolchain maintenance rather than being hidden behind a production-clean claim.

Before merge, CI and the protected Vercel preview must pass again on the final
pushed commit.

## Installation and rollback

Install from the committed lockfile with `npm ci`; do not substitute an
unreviewed package resolution. Release only the reviewed commit through the
existing procedure. Preserve the current production deployment as the rollback
target until the promoted revision passes public readback.
